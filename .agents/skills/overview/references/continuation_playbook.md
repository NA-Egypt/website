# 🧭 Continuation Playbook: Formulating Next Steps

A great session overview doesn't just look backwards—it drives forward momentum by presenting clear, decision-ready options.

---

## 1. Prioritization Framework
When suggesting next steps, organize by priority:
- **Priority 1: Verification & Integrity** (Running regression tests, reviewing diffs with `/review`, fixing broken builds).
- **Priority 2: Immediate Feature Continuation** (Implementing the next natural endpoint, UI view, or data handler).
- **Priority 3: Hardening & Polish** (Error handling, input validation, logging, documentation).
- **Priority 4: Deployment & Release** (CI/CD pipeline triggers, tagging release, updating changelog).

---

## 2. Decision Trees
If the user faces multiple paths forward, outline the trade-offs:
- **Path A (Fast Prototype)** vs **Path B (Production-Hardened)**.
- **Option 1 (Automated Tests first)** vs **Option 2 (Manual verification)**.
